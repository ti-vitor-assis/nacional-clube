# Nacional Clube

Site da loja oficial **Nacional Clube**: streetwear brasileiro que junta a alta costura com a cultura nacional.

## Estrutura

```
nacional-clube/
├── index.html            # Página principal
├── style.css             # Estilos personalizados (cores e fontes da marca)
├── script.js             # JS personalizado
├── img/produtos/         # Fotos dos produtos
├── bootstrap-4.1.3/      # Bootstrap (CSS e JS)
└── script/               # jQuery e Popper
```

## Fotos dos produtos

Coloque as imagens em `img/produtos/` com estes nomes:

| Arquivo                          | Produto                          |
| -------------------------------- | -------------------------------- |
| `camiseta-sao-paulo-garoa.jpg`   | São Paulo — Terra da Garoa       |
| `camiseta-tropical-cyan.jpg`     | Tropical Ciano • Preto Estonado  |
| `bone-veludo-cotele-marrom.jpg`  | Boné Veludo Cotelê Marrom        |

## Como rodar

Abra o `index.html` no navegador (ou use a extensão Live Server do VS Code).
